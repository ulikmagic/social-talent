# 🎯 Цель: харизма — карта пути

> Главная цель всей работы. Харизма по Кэбейн — **набор навыков, не врождённое качество**. Это идеально ложится на инженерный стиль Улика.

## Модель Кэбейн: 3 компонента и статус Улика

| Компонент | Что это | Статус | Что блокирует / что качает |
|---|---|---|---|
| **Присутствие** | Быть полностью в моменте, полное внимание собеседнику | 🟡 | Блокирует: внутренний диалог, тревога, DMN-руминации. Качает: экспозиция тишиной, фокус наружу (его же правило из «Наблюдательности») |
| **Сила** | Восприятие способности влиять на мир | 🟢 | Уже есть: «3 из 200», результаты, дисциплина. Блокирует только неумение это транслировать (позиция «снизу») |
| **Теплота** | Искренняя забота, эмпатия | 🟡 | Эмпатия есть (глубокая, через анализ), но за стеной шизоидной защиты + эмоциональное онемение глушит трансляцию |

## Его естественные типы харизмы (не распыляться на все 4)

1. **Фокус-харизма** (Билл Гейтс): глубоко слушает, человек чувствует «он видит меня». Его аналитический ум + глубина = природное преимущество.
2. **Авторитетная харизма**: компетентность + результаты. «3 из 200» уже работает.
3. Визионерская — потенциал через проект «Социальный талант» (система, которую можно передать другим).
4. Харизма доброты — в процессе, не форсировать: теплота выйдет сама, когда снимется шизоидная стена.

**Целевой образ**: человек, который глубоко слушает, видит суть и добивается результатов. Интроверсия — не барьер, а преимущество (глубокое слушание, аутентичность вместо перформанса).

## Что конкретно стоит между Уликом и харизмой

Цепочка блокировок (по каскаду из [[01-профиль-личности]]):

```
Тревога/ПРЛ сжирает ресурс
    → эмоциональное онемение (нет вайба для резонанса)
    → шизоидная стена (эмпатия не транслируется наружу)
    → депрессивное ядро (позиция «снизу», не принимает признание)
    → внутренний диалог/страх ошибки (нет присутствия)
```

Отсюда порядок работы — **изнутри наружу**:
1. **Ресурс**: снижение тревоги (экспозиция тишиной, триггеры) → возвращается энергия на эмоции. Доказано: «в моменты без тревожности мгновенно появлялась куча эмоций, чувствовал себя живым».
2. **Разморозка эмоций**: снятие запрета «нельзя радоваться — будет расплата» через мини-цели и безопасный опыт.
3. **Присутствие**: тренировка «всё внимание наружу», микро-спринты фокуса на собеседнике.
4. **Позиция**: из «просителя» в «равного» (уже отработано на кейсах Жазиры и Махжана). Убрать слова-сомнения, язык фактов, уверенные паузы.
5. **Трансляция**: невербалика, энергообмен, «послевкусие» — его же принципы из старой схемы.

## Его собственная система (использовать, не изобретать заново)

### Старая схема (проработана глубоко)
- **База = 8 пакетов**: Контекстное мышление, Риторика, Социальные правила, Эмоциональный интеллект, Наблюдательность и реакция, Коммуникабельность, Невербальное общение (не готово), Внешние параметры (не готово).
- **Формула навыка**: умение из пакета А + умение из пакета Б + ... = Навык (пример: «Налаживать первый контакт» собран из 7 умений).
- Ключевые формулы: Риторика = Логика + Эмоция + Авторитет; Контекст = Где + Когда + Кто + Настроение + Ситуация + Причина; Соц. свобода = Статус + Контекст + Баланс сил; ЭИ = Опора (понимание себя + самоконтроль) + Радар (эмпатия) → Влияние.
- Коммуникабельность: цикл контакта, система «крючков», архивация данных о людях, мост в будущее, энергообмен, искусство паузы.

### Новая схема (текущий репозиторий, в основном пустая — точка роста)
- **База данных**: психотипы (готов 1: доминантно-статусный/давящий — кейс Махжан), формулы, данные об обществах, практики — почти всё пустое.
- **Модификаторы**: Внешность, Стиль, Запах, Цифровой образ, Среда — все пустые.
- **Процессы (canvas)**: Цель → Контекст (где я, положение, ресурсы) → Инструменты → Что делать сейчас → Ошибки/Результаты → Сверка с целевой картиной в процентах.

## Диагноз затыка (06.07.2026): уровень 2 — углубление контакта

- **Легко даётся**: первый контакт, small talk на общие темы (мемы), иногда юмор. (Навык «первый контакт» из старой схемы — фактически собран.)
- **Клинит**: удержание/продолжение разговора, конфликт, юмор. Сцена-маркер: коллеги сами заводили разговор — не смог продолжить → сильный контакт не построен. **Сцена пожарной тревоги**: все вышли на улицу, стоят группами — ему не с кем встать. Это метрика нулевой точки.
- Суть: типично шизоидный профиль — контакт до порога близости. Разговор №1 умеет, разговоры №2–№10 (превращение знакомого в «своего») — целевая зона плана.
- **Граница (вопрос 4)**: жёсткие конфликты — НЕ готов. Всё остальное можно.

## Идея-кандидат на «двигатель» плана (его собственная)

**Косплей + выступление на комиконе + завести там друзей.** Его формула: «сценарий из детства → разрушить новым опытом». Бьёт точно: детская сцена «задрот без друзей, жизнь идёт без меня» + родная стихия (аниме) + сцена/внимание (легальный выход истерическому радикалу 7.3) + повтор успешной механики Астаны с усилением. Блокер: «странная апатия» при мысли о подготовке — разобрана в [[04-прл-на-пути]].

## Правило из его опыта (核心)

Триггеры и страхи отваливаются **не от прямой борьбы с ними, а от реальных побед** (опыт Астаны: успех на Comic Con + друзья → страх вечера исчез сам). Значит путь к харизме = серия спроектированных побед с фиксацией, а не «работа над недостатками».
