# Формулы

> Заполняется только из реальных боёв.

## 1. Приватный канал во время публичного конфликта (кейс MR, 14–16.07.2026)

**Когда**: в групповом чате/на встрече разгорается конфликт, где твоё оправдание подставляет союзника.

**Формула**: не оправдываться публично → вытащить ключевого игрока в приватный канал (курилка, ЛС) → показать, что защищаешь его интересы раньше своих («если объясню в чате — подставлю тебя») → синхронизировать позиции → вернуться в публичное поле с согласованной линией.

**Почему работает**: лояльность, показанная в момент риска, возвращается с процентами — союзник сам публично закрывает тебя (Мадияр: «Улугбек не виноват, скидывайте псов на меня»). Публичное оправдание дало бы обратное: правоту ценой союзника.

**Проверено**: конфликт «MR без аппрувов» — извинение Айданбека + публичная защита от 5 человек.

## 2. Ответ контроллеру в момент атаки (тот же кейс)

**Никогда**: «неважно», отмахивание, шутка над правилом (для контроллера это плевок в закон → эскалация «важно.»).

**Формула**: факты без вины + обещание структуры: «предлагал идти по регламенту, решение принято выше, детали опишу списком завтра». Затем обещание ИСПОЛНИТЬ — списком, в срок.

## 3. Фиксация решения «мимо регламента» (родилась из кейса, согласована с Мадияром)

Если лид/СТО решает идти мимо процесса — решение фиксируется одним сообщением в чате В МОМЕНТ принятия («заливаем без 2 аппрувов по решению X, причина Y»). Исполнитель покрыт, патрулю есть документ. → Вставить в регламент.
