# Навык: вайбовый small talk (образец — Алмас)

> Сборка по формуле старой схемы: **Навык = умение из пакета А + умение из пакета Б + ...** ([[_resources/старая схема/социальный талант|социальный талант]]).
> Колонку «Наблюдение» заполняет Улик в четверг (день Алмаса) и далее — только из реальных сцен, не из теории. Цель Улика по этому навыку: 20% → 60%.

## Разложение навыка по пакетам Базы

| Пакет | Гипотеза: что делает Алмас | Наблюдение (заполнить из реальных сцен) | Приём для кражи |
|---|---|---|---|
| Контекстное мышление | Выбирает лёгкий момент: кухня, обед, перерыв — не влезает в занятость | | |
| Коммуникабельность | Заход «ни о чём» без цели и без напряга; оставляет приятное послевкусие | | |
| Наблюдательность и реакция | Считывает настроение и подхватывает чужие реплики, а не ждёт своей очереди говорить | | |
| Эмоциональный интеллект | Энергообмен в плюс: после него легче, не тяжелее; сам расслаблен | | |
| Невербальное общение | Поза, улыбка, тон — «не всерьёз», расслабленно | | |
| Риторика | Подача важнее контента: эмоция и интонация делают банальную тему живой | | |
| Социальные правила | Знает, с кем можно шутить и до какой границы | | |

## Что записывать в четверг (минимум 3 приёма)

1. **Как он заходит** в разговор: первая фраза дословно, к кому, в какой момент.
2. **Как поддерживает**: что делает, когда собеседник ответил коротко? как подхватывает?
3. **Как выходит**: чем заканчивает, остаётся ли зацепка.
4. Бонус: что он делает в паузах (заполняет? держит?).
