# Шаблон: локальный образ

> **Локальный образ** (термин Улика, 04.08.2026) = связка **человек + ситуация + конкретное превосходство**. Не «какой человек вообще», а «что у него в этой ситуации получается лучше, чем у остальных».
> Примеры: Исаги — удар в полёте. Алмас — попадание мемом в контекст в кухонном трёпе. Мадияр — защита своих под публичным давлением.
>
> **Зачем так**: «стать как Алмас» невозможно и не нужно. Снять его локальный образ — возможно. Собранные локальные образы складываются в собственный навык — это его же схема «Навык = умения из разных пакетов», только теперь у частей есть источники.
>
> ⚠️ Не путать с **психотипом** (Махжан, Айданбек, вахтёр) — тот отвечает «как с ним обращаться, чтобы не пострадать». Локальный образ отвечает «что у него забрать».

---

## Шапка

**Кто**: имя, роль, возраст
**Ситуация**: 1-на-1 / малая группа своих / публично, большая группа / незнакомцы / стресс и конфликт / флирт
**Локальный образ одной строкой**: что именно он делает в этой ситуации лучше остальных

---

## 1. Внешние параметры
Одежда, уход, форма, аксессуары, образ. Что из этого — сигнал и о чём.

## 2. Какие эмоции вызывает
Каким человек уходит после разговора с ним: заряженным, расслабленным, уважающим, настороженным. Главный измеритель — люди помнят состояние, а не слова.

## 3. Тело, мимика, голос
Поза, дистанция, руки, взгляд. Что показывает лицом, а что нет. **Голос отдельно**: громкость, темп, паузы.

## 4. Как заходит
Первая фраза дословно. К кому, в какой момент, с какого расстояния, под каким поводом.

## 5. Как удерживает ← главный дефицит Улика
Что делает, когда собеседник ответил коротко. Как подхватывает чужие реплики. Что делает в паузах — заполняет или держит. Как переводит с общей темы на личную.

## 6. Как заканчивает
Чем завершает, оставляет ли зацепку, уходит ли первым. (Пик и финал запоминаются сильнее середины.)

## 7. Что он НЕ делает
Не суетится, не оправдывается, не объясняет шутки, не выпрашивает реакцию, не заполняет тишину. Отсутствия копируются так же, как приёмы.

## 8. Где ломается
В какой ситуации этот же человек плох (Алмас в стрессе, Махжан без сопротивления). Две задачи: не тащить образ в чужую клетку и увидеть цену стиля — за каждый стиль чем-то платят.

## 9. Границы применимости
Где приём даст обратный эффект. Оплаченный пример: стёб Алмаса работает при накопленном доверии и не работает без связи (кейс Айгерим).

## 10. Вывод
- **Беру**: 1–3 конкретных приёма (не «его уверенность», а «пауза перед ответом»).
- **Не беру** и почему.
- **Первая проба**: где, когда, в какой ситуации.

## Матрица локальных образов

Одна клетка = один локальный образ. Заполняется по мере наблюдений.

| | 1-на-1 | Малая группа | Публично | Незнакомцы | Стресс | Флирт |
|---|---|---|---|---|---|---|
| **Алмас** | | ✅ мем в контекст | | | ⚠️ ломается | |
| **Мадияр** | ✅ прямота без церемоний | | ✅ защита своих под давлением | | ✅ держит рамку | |
| **Степан** | | | | ← первый контакт | | |
| **Гоша** | | | | | | ← ? |
| **Юра** | | | ← ? | ✅ подход | | ✅ объём контактов |
| **Айданбек** | | | ✅ держит правило против иерархии | | | |

**Правило**: не переносить приём из клетки в клетку без проверки. Человек, сильный в своей клетке, в чужой — худший из возможных образцов.
